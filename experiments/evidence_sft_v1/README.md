## 预先定义的评估

三组模型：原始Qwen2、第一轮30k LoRA、第二轮新LoRA。统一输入证据、system/instruction模板、后端、解码和输出长度，先评固定证据生成；端到端检索另测。第二轮先从原始模型新建适配器，不覆盖第一轮。

逐题审阅字段：
- answerability_gold：all / partial / none（事先标注）。
- required_facts_covered：目标要点覆盖数/总要点数。
- unsupported_claims：资料外事实数；具体孕周、品牌、剂量、数值等分别记录。
- citation_supported_claims / factual_claims：检查陈述是否由所引片段支持；仅编号存在不计支持。
- wrong_refusal：有充分证据却完全拒答；部分可答而全拒也单列。
- condition_population_error：条件、人群或比较符改变。
- latency、truncation：计时与截断，注明是否含检索/缓存。

先按分母分别报告，不把多指标混成无解释的综合分。两名评审可行时独立判定并讨论分歧；否则明确单人/助手评审限制。ROUGE只作辅助。规则压力案例不混入医学问答分母。

模型选择只看开发集，冻结配置后一次性报告保留测试结果；若据测试结果再调参，该集转为开发，另建保留集。通过上线前至少要求相对原始模型：有依据题覆盖改善、资料外细节及错误拒答没有明显恶化，并检查旧QA回归。显著性与置信区间需实际逐题结果，当前不预填。
