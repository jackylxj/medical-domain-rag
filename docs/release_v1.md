# 发布版 v1.0.0

项目名称：**基于领域适配大模型与 RAG 的医疗问答系统**。

## 冻结内容

- 在线：Qwen2-7B-Instruct 原始指令模型，Prompt v2。
- 检索：CPU 常驻 BGE-large-zh-v1.5、Milvus Lite、Top-3；v2 语料 6 篇摘要、24 个片段。
- 服务：FastAPI 单 worker、vLLM、Redis 完全匹配缓存，TTL 3600 秒。
- 适配：第一轮 Huatuo 30k LoRA，500 题保留测试集结果。
- 候选第二轮数据与诊断脚本归档，不新增训练或实验分支。

## 运行与验收

按[复现指南](reproduction.md)准备分离环境、模型、数据与索引，然后按[常驻服务说明](resident_services.md)启动。检查服务健康状态，提交有证据、资料外、重复问题，核对返回答案、证据和缓存状态。

发布验收使用既有模型、索引与提示词，只检查部署链路，不计为新模型质量实验。最新验收记录见 [release_acceptance.json](release_acceptance.json)。

本地源码及源码包解压后的 73 项测试均通过。云端有证据、重复和资料外请求均完成；本次耗时分别为 8.6019、0.0699、0.8091 秒，重复请求命中缓存并跳过生成。这是当次验收观测，与此前性能测试分开记录。对已保存的 test500 两组预测逐题复算，确认 16.8071 → 26.9119，问题和参考答案顺序一致。

## 源码交付

运行 python -m scripts.package_source 生成 dist/RAGDemo-source.zip。白名单排除本地环境、凭据、原始数据、权重、运行输出、个人 CV 和内部计划。源码清单及 SHA256 用于核对包内容。

README 和实验报告是展示入口；历史报告中的“下一阶段”表示当时提出的研究方向，当前实施状态以本页为准。
