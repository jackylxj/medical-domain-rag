# 三阶段证据问答实验 v1（2026-11-05）

## 目的与范围

检验“定位原文 → 基于摘录回答 → 审核事实与引用”是否能改善错误拒答，同时抑制资料外细节。实际执行18道已经见过的开发题，复用之前保存的相同Top-3证据，不重新检索，不使用Redis，不修改在线网页配置。没有把这18题称为盲测。

模型为在线原始Qwen2-7B-Instruct / vLLM，三阶段都使用同一个模型。各请求固定temperature=0、top_p=1、seed=42、max_tokens=512、repetition_penalty=1；阶段输出使用JSON模式，v2基线仍为普通文本。它是整体流程对比，不是只改变一个提示词的消融。

## 实现

1. 定位：模型输出引用编号和逐字摘录；程序检查摘录是否为对应原文的连续子串。不存在、空摘录或非法编号拒绝通过。
2. 回答：模型依据已核对摘录输出claims及缺失信息；程序检查非空内容及引用是否来自定位结果。
3. 审核：模型逐条判断候选事实与所引用证据的关系；程序检查审核索引完整、无重复，且supported必须为布尔true。任一条未通过则暂不输出候选结论。

资料定位为空时提前结束。程序不把模型生成的missing解释原样展示，只附通用不足说明。输入、完整请求、响应、原文摘录、草稿、审核理由与耗时均保存。

原文子串验证只证明文本存在，不证明文本与问题相关。JSON模式只保证输出形式，不保证语义正确。同一模型自审可能重复生成阶段的错误。

## 结果

| 状态 | 数量 | 含义 |
|---|---:|---|
| 模型审核接受 | 10 | 不等于10题正确 |
| 模型审核拒绝 | 3 | 其中两例为误拦，另一例拦住成人/儿童人群不匹配 |
| 未定位到支持证据 | 5 | 这些题在给定资料中确实缺少所问细节 |

共44次阶段请求，加18次同轮v2基线请求，总计62次。所有请求正常stop结束，无截断。18题三阶段平均3.648秒、中位数3.955秒、范围0.220–8.766秒；同轮v2生成请求均值0.566秒。提前结束的资料外题减少了平均耗时。这是单次串行小样本，不含检索、缓存、服务启动或浏览器网络，不是P95/并发压测。

### 改善

- 400毫克钠换算1克食盐：原v2错误拒答，本轮正确回答。
- 冷冻蔬菜否定问法、冷冻蔬果选择条件：原v2错误拒答，本轮能回答；否定问法的回答仍较简略。
- 两个具体孕周问题：定位阶段结束，没有再输出上一轮简短提示词产生的资料外具体孕周。
- 儿童盐摄入问题：定位器错误选入成人证据，回答器输出成人指标，审核器识别人群不匹配并阻止该候选输出。此例相对v2不是新增正确答案，而是展示内部错误被拦截。

### 仍有问题

- **漏检**：题1把原文“低于5克”改成“不超过5克”，审核通过。严格不等号边界发生变化。
- **误拦**：题3候选句“只计算烹调时添加的盐，不能反映全部钠摄入”有原文直接支持，却被审核拒绝。
- **误拦**：题13依据1克对应400毫克，计算800毫克对应2克正确，审核器却要求原文必须直接出现800毫克的结果。
- **完整性问题**：久坐复合问题的missing字段与已经回答的比较关系矛盾；只能给出部分回答。
- **逐句检查不足**：题8在一个claim里放了两句话，程序只验证claim结构，没有强制中文句子分割；因此仍不能宣称逐句支持全部验证完成。

上述评审是助手对照输入证据作出的开发检查，不是医学专家正确率评估。

## 结论与下一步

流程提高了部分可回答性，并提供可审计中间过程，但同模型自审出现两例明确误拦和至少一例边界漏检。因此暂不替换网页v2，不宣称全面胜出。

下一步应先增强可确定验证的部分：数值比较符、单位与适用人群保留；原文直接摘录与基于显式比例的计算分开处理，计算使用受限算术校验；把claim规范为单句。程序检查结果与模型语义审核分开记录，未通过时显示原文证据供人工确认。避免通过编写本题关键词规则来制造通过率。仍需冻结独立新问题集评估泛化。
