# 候选开发题提示词对照

> 发布归档：以下为已完成的开发实验。“后续”部分记录当时提出的研究方向；v1.0.0 不启动第二轮训练，当前实施状态见 ../release_v1.md。

保持12题、证据、基础模型、第一轮30k适配器、BF16、聊天模板与解码参数不变，只在user消息末尾追加通用作答要求：逐部分回答、逐事实句引用、明确缺失、不补充材料外知识。system消息不变，不在指令中加入具体题目的答案。

同一个临时vLLM进程先重跑short指令作为当次对照，再运行strict指令；每种指令下均交替请求base和LoRA，共48次生成。短指令复跑用于检查与上一轮的可重复性。重跑差异须如实记录，不能选择性丢弃回答。

评审沿用上轮规范：相对输入的无依据扩展、有依据部分覆盖、资料不足边界、逐事实句引用支持、空答及截断。预期引用数量的分母是9条包含已知事实的问题；3条纯资料不足题不应强制加引用。模型生成的引用必须核对支持关系。由助手审阅，不作为独立医学准确率。

仍是开发实验；不读预留测试正文、不训练、不修改在线提示词。完成后恢复原生成服务，并保存启动命令、环境、数据与适配器哈希、原始响应和逐题审阅。

运行入口：`python -m scripts.evaluate_candidate_baseline --prompt-version short|strict --output 新目录`。strict完整文本保存在脚本常量STRICT_INSTRUCTIONS和每条请求payload中。

## 运行结果（2026-11-05）

48次生成全部完成。旧short复跑24/24答案与前次逐字相同。三次运行的数据、适配器、模型配置、分词器配置哈希及环境版本均相同；同题short/strict除user尾部追加指令外，请求其他参数完全相同。原始模型与LoRA共用同一个临时vLLM引擎。

| 观察项 | 原模型 short → strict | 30k LoRA short → strict |
|---|---:|---:|
| 扩写给定证据外事实（12题） | 4 → 1 | 1 → 0 |
| 未回答已提供的信息：错误拒答/漏答（9题） | 0 → 1 | 0 → 6 |
| 纯资料不足题守住边界（3题） | 1 → 3 | 2 → 3 |
| 带引用编号的回答（12题；非引用正确率） | 2 → 7 | 0 → 0 |

两种strict模型均无空答、无长度截断、无非法引用编号。0个非法编号也可能因为根本没有引用，不能当作成功指标。原模型strict的7条带编号回答也不是7条全部合格：肺炎复合题仍有扩展和引用缺失，另一条肺炎题只在第二句标号。

表中“证据外扩写”不包括错误声称“资料未提供”的情况；后者单独计入错误拒答/漏答。short原模型pneumonia-03仍有自相矛盾的开头，但随后确实说出已知信息，所以不计入“未回答已提供信息”。所有计数是助手相对输入证据的审阅，不是独立医学准确率。

## 关键变化

- 两组hepatitis-04都不再补充输入未提供的“24小时”，3条纯资料不足题都能保持边界。
- 原模型在hepatitis-01把“是否只可能急性”误当成资料不足；原文明确有急性或慢性。
- LoRA在depression-02、hepatitis-01、hepatitis-02直接错误拒答；在depression-03、pneumonia-03只回答缺失部分而漏掉已知部分；在pneumonia-02错误否认高风险儿童类别已提供，并漏掉“免疫系统受损”的直接答案，共6条。
- 原模型pneumonia-01仍引入资料没有的空气容量、二氧化碳排出说明；只有风险类别句给出[1]，肺泡部分所需的[2]未标注。
- 原模型depression-03回答了“至少两周”，但漏掉对量表分数缺失的说明；该问题属于部分回答不完整，和漏答已知部分分开记录。

逐题四组回答对照：`outputs/evidence_candidate_prompt_strict_v1/review.md`。审阅标签和回答哈希：[review JSON](evidence_candidate_prompt_v1_review.json)。原始输出在control与strict两个目录，未覆盖前次baseline。

## 结论与后续

加强指令可以减少这批题的证据外扩展，但不是整体解决方案：LoRA的引用仍为0，而且过度拒答明显增加。只能说明这批开发题上存在提示词与模型行为的交互，不能把失败简单归为“训练坏了”或“只要换提示词”。旧QA微调任务与基于证据的引用/部分回答任务不同，仍是后续应检验的假设。

本轮不部署strict指令，保持原网页行为。下一阶段进入小规模任务对齐数据扩充：以新的事实单元制作约200条训练候选，优先覆盖应回答、否定前提、多证据及部分回答，保留资料不足样本；逐条核对依据，不只改写现有18个事实。开发来源保持分离，预留测试不参与选择。经质量核验后从原始Qwen2开始训练新LoRA，固定提示词再与原模型及旧30k LoRA对照，不在旧适配器上盲目追加训练。
