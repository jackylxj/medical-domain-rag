# 确定性证据规则：保存草稿回放（2026-11-05）

## 本轮工作

新增 scripts/evidence_rules.py 与 scripts/replay_evidence_rules.py，复用三阶段实验保存的18题草稿。没有新模型请求、没有修改网页、没有宣称生成质量已经提高。目的为隔离程序检查的作用。

规则覆盖：
- 检查引用编号，识别一个claim包含多个中文句子的情况；分句不切断小数点。
- 在列出的阿拉伯数字/单位范围内检查新数量是否出现在引用证据中；单位不同也视为不同数量。
- 对相同数字与单位检查比较符，例如“低于”与“不超过”。这是严格保留边界的检查，不是完整自然语言蕴含判断。
- 检查显式成人/儿童用词冲突，不是通用人群分类器。
- 原文连续片段能证明文本存在；不能证明其回答了问题。
- 限定钠与食盐的关系语法，提取原文比例，用Decimal验证乘除结果；不使用eval、不执行模型代码、不硬编码400或800。互相矛盾的比例、额外建议、未支持的关系句式不出具计算证明。

## 验证与边界

新增14项规则测试，覆盖比较符、单位、不同数值/小数比例、错误算术、冲突比例、额外建议、分句、人群及非法引用。否定关系测试先失败，之后收紧为关系所在分句必须完全匹配支持格式。全项目46项测试通过。额外数值为规则测试，不是独立LLM盲测。

这不是通用医学验证器。中文数字、复杂范围、跨句否定、隐含人群、同单位但不同实体、因果关系及复杂推导都没有全面覆盖。单位检查不自动做所有单位换算。语法不匹配时保持未验证，不代表事实错误。规则只输出审计结果，不重新生成或替用户直接选择答案。
