# 提示词控制变量诊断（2026-11-05）

## 设计与实际执行

使用在线原始 Qwen2-7B-Instruct/vLLM，直接调用生成端，绕过 Redis 与检索。使用原先保存的相同证据，固定 temperature=0、top_p=1、seed=42、max_tokens=512、repetition_penalty=1。

三个实验组：

- baseline_v2：原系统提示词与原 v2 用户提示词。
- concise_user：系统提示词不变，只将用户规则换成较短的直接证据问答规则，允许同义、否定和明确换算关系。
- concise_both：用户规则同上一组，再替换为简短系统提示词。

原开发集12题，每组12次；之后补充6个问法/资料外细节检查，每组6次。共54次请求。后6题在观察第一轮后设计，不能称为盲测或独立正式测试集。检索证据复用，不评估新问法的召回表现。

脚本：scripts/diagnose_prompt_v4.py、scripts/check_prompt_v4_followup.py。
原始请求、证据、回答、finish_reason、token与服务指纹保存于 outputs/prompt_diagnostic_v4 和 outputs/prompt_diagnostic_v4_followup，不随源码分发。两脚本为本次诊断记录，依赖之前的私有实验输出。

## 关键对照

| 检查 | v2 | 只简化用户提示词 | 同时简化系统提示词 |
|---|---|---|---|
| 400毫克钠换算 | 错误拒答 | 依据给定关系回答1克 | 同左 |
| 冷冻蔬菜是否一定不适合 | 错误拒答 | 回答不能仅凭冷冻判断 | 回答没有证据表明不适合，条件保留较弱 |
| 800毫克钠换算（追加） | 错误拒答 | 依据关系回答2克 | 同左 |
| 冷冻蔬果选择条件（追加） | 错误拒答 | 正确提及无添加糖/不过量钠 | 同左 |
| 原问法询问具体孕周 | 合理拒答 | 编出资料中未提供的24–28周并引用[1] | 说明没有具体孕周，但仍挂引用 |
| 新问法询问具体孕周 | 合理拒答 | 再次给出资料外24–28周并引用[1] | 增加资料外早期筛查等信息 |
| 久坐复合问题 | 引用不充分 | 仍有无直接证据表述/引用覆盖问题 | 同样未解决 |
| 儿童盐摄入上限（追加） | 合理拒答 | 说明缺少儿童数据，但挂引用 | 说明缺少儿童数据 |

这里的“资料外”是相对于实际传入的证据判断；即使某项内容可能来自模型背景知识，也不满足限定资料问答要求。本报告不是临床指南正确性评审。

## 原因判断与局限

1. 两道典型错误拒答的相关证据已经位于输入中，且仅改用户提示词就改变结果，说明生成对指令表达敏感。不能归因于未召回、缓存错误或模型未启动。
2. v2较保守，新规则提高可回答性却降低资料边界遵守。单次实验不能将机制精确归因于某一个词，也不能排除模型本身指令遵循能力的限制。
3. 进一步修改系统提示词未得到稳定提升，并在新孕周问法上扩写。没有证据支持直接替换上线。
4. 引用编号存在且合法，仍可能引用到不支持具体数字的片段。编号正则检查只验证格式，不验证蕴含关系。

## 决策与下一步

保留网页v2；未修改生产提示词、模型、索引或缓存配置。本轮是有改善也有明显回归的候选实验，不称为全面优化成功。

下一步应采用可审计的“证据定位→作答→逐句支持检查”设计，而非继续堆叠提示词：先要求输出能支持答案的原文片段与编号，程序验证摘录确实存在；数值/单位单独对照；没有明确支持时回退为证据展示或说明缺失。原文存在性不能代替语义支持验证，不能据此宣称杜绝幻觉。保留这18题为开发回归集，再另外冻结独立问题集检查质量与额外延迟。该流程尚未实现。
