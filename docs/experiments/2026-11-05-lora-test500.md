# 中文医疗问答 LoRA 复现实验

2026 年 11 月的公开复现。以下数字来自操作者提供的魔搭云端汇总。基座为 Qwen2-7B-Instruct，LoRA 使用 Huatuo26M-Lite 的 30,000 条训练样本训练 1 个 epoch。两组在相同的 500 题保留测试集上使用 evaluate.py 生成回答。本轮均未启用 RAG。

| 模型 | 字符级 ROUGE-L F1（0–100） | 达到输出上限 | 空回答 |
|---|---:|---:|---:|
| Qwen2-7B-Instruct | 16.8071 | 2/500 | 0 |
| Qwen2-7B-Instruct + LoRA | 26.9119 | 8/500 | 0 |

用未舍入的均值相减，提升 10.1047 分。按题计算参考答案和生成文本的字符级最长公共子序列 F1，去空白、保留标点，再取平均并乘以 100。该指标衡量措辞重合度，医学正确性需要另行评审。

验证阶段（dev100）基座、3,000 条 LoRA、30,000 条 LoRA 依次为 16.39、25.43、25.83。最终测试只比较基座和已选定的 30,000 条 LoRA。

云端结果目录为 `outputs/eval_base_test500_v2/` 与 `outputs/eval_30k_test500_v1/`。本记录据汇总整理，未逐题复核预测。后续可用两个目录中的 config.json 核对测试文件哈希，用 predictions.jsonl 按来源索引比较回答；原始问答与预测保留在私有实验备份。
