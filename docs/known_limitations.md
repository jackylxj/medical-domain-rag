# 已知失败案例

保留以下失败，不通过删题提高报告数字：

| 案例 | 观察 | 结论 |
|---|---|---|
| 400 毫克钠换算食盐 | v2 拒答，证据已给出换算；v3 能答 | 召回不保证生成完成任务 |
| 冷冻蔬菜是否一定不适合健康饮食 | v2/v3 拒答；Top-1、Top-3、中性改写仍拒答 | 这些干预未解决问题，不能归因于某个词 |
| 久坐与活动复合问题 | 引用不完整；v3 增加无证据的比较 | 引用编号合法不等于事实受支持 |
| 减钠食品选择 | v3 扩写证据未提供的建议 | 回答更长不等于更好 |
| LoRA RAG 风险因素/行动计划 | 原始模型能答，LoRA 错误拒答 | 当前开发案例支持选择原始模型，不宣称一般性优劣 |
| 未提供的药名、剂量、孕周 | 开发检查中拒答 | 不代表所有安全边界已验证 |

当前保留 v2。Redis 会复用错误拒答；vLLM 和常驻服务只改善运行方式，不自动改善质量。

RAG 问题已用于提示词调整，不是独立盲测。LoRA 500 题与 RAG 开发题不同，不能拼成三列 ROUGE 趋势。规则去重不保证消除所有语义重复，公开 QA 未经逐条专家审核。

后续质量工作：冻结语料、提示词及标注规则，再构建独立问题集，分别评估召回、答案完整性、逐句证据支持与合理拒答。当前源码发布应如实保留这些限制。
