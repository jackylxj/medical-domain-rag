# 项目一实验报告

项目名称：基于领域适配大模型与 RAG 的医疗问答系统。实验与复现记录时间：2026 年 11 月。发布版冻结既有在线系统和第一轮 30k LoRA。

## 领域适配

使用 Qwen2-7B-Instruct，通过 LLaMA-Factory 完成 LoRA 监督微调。Huatuo26M-Lite 经格式检查、规则去重与固定随机划分，排除 smoke 试跑样本后形成 30,000 条训练、500 条验证、500 条测试；3,000 条 pilot 是训练子集，dev100 是验证子集。规则去重不等同于语义去重。

| 配置 | 数值 |
|---|---|
| GPU | NVIDIA A10，23,028 MiB |
| LoRA | q_proj / v_proj；rank 8；alpha 16；dropout 0.05 |
| 训练 | BF16；1 epoch；cutoff_len 512；batch 1；梯度累积 4 |
| 优化 | 学习率 1e-4；cosine；warmup_ratio 0.05；seed 42 |
| 30k 训练耗时 | 6,897.023 秒，约 1 小时 55 分钟 |
| train_loss / eval_loss | 1.5780 / 1.5538 |

| 保留测试集（500 题） | 字符级 ROUGE-L F1，0–100 | 达到输出上限 | 空回答 |
|---|---:|---:|---:|
| 原始 Qwen2-7B-Instruct | 16.8071 | 2 | 0 |
| Qwen2-7B-Instruct + 30k LoRA | 26.9119 | 8 | 0 |

提升为 **10.1047 分**。逐题去除空白、保留标点，计算字符最长公共子序列 F1，再取均值乘以 100。该指标衡量参考答案的措辞重合度，不是医学准确率，也不能与不同分词方式的 ROUGE 直接比较。

两组保存配置的测试集 SHA256 相同：537f93646f394009f0a458570b8116d55b83d5f2a1e224743475f591401da6a7；system、BF16、qwen 模板、do_sample=false、max_new_tokens=512 一致，区别为是否加载适配器。[详细记录](experiments/2026-11-05-lora-test500.md)。

## 检索与知识库

Markdown/TXT → 按章节切分 → 长章节字符滑窗 → BGE-large-zh-v1.5 → Milvus Lite。每片段保存来源、章节、版本和定位信息；编码前核对 tokenizer 长度。v2 语料为 6 篇公开资料摘要、24 个片段。

首版 12 题 / 12 片段开发检查：Hit@1=11/12，Hit@3=12/12，MRR@3=0.9583。结果属于 v1 开发集，不移植为 v2 检索准确率。v2 检查覆盖新增知识、跨片段问题和资料不足。

## 模型选择与评估

在线版冻结为原始 Qwen2-7B-Instruct + Prompt v2 + Top-3 检索。领域 QA 微调改善保留测试集措辞匹配，但开发题中 LoRA 的引用与完整回答没有同步改善，因此分别记录微调成果和在线选择。

后续开发诊断固定证据、模型与解码参数，对照 short / strict 指令：

| 观察项 | 原始模型 short → strict | 30k LoRA short → strict |
|---|---:|---:|
| 证据外事实扩写（12 题） | 4 → 1 | 1 → 0 |
| 已知信息错误拒答或漏答（9 题） | 0 → 1 | 0 → 6 |
| 纯资料不足题保持边界（3 题） | 1 → 3 | 2 → 3 |

短指令复跑 24/24 回答逐字一致。以上是相对输入证据的开发审阅，不是独立专家医学测评。更强指令减少扩写，同时可能增加漏答，因此不替换网页提示词。[逐题条件与审阅](experiments/evidence_candidate_prompt_v1.md)。证据定位、生成和规则核验探索作为研究档案保留。

## 服务与性能

FastAPI 任务服务、CPU 常驻 BGE/Milvus Lite、GPU 常驻 vLLM 分离部署。Redis 对问题及模型、语料、提示词、部署上下文构造缓存键，支持 TTL 与故障回退。单 worker、串行任务为本次验证配置。

| 场景 | 样本与结果 |
|---|---|
| 常驻服务，应用答案缓存未启用 | 5 次串行任务；首次 7.97 秒，后四次 0.75–1.49 秒 |
| Redis 配对验证 | 3 组；未命中 0.7601–1.0214 秒，命中 0.0383–0.0528 秒 |
| 缓存功能 | 答案与证据一致；TTL 到期；版本上下文变化失效；Redis 不可用时继续生成 |

计时包含服务端任务处理，不含启动、浏览器轮询和外部网络。缓存命中时间不是模型生成时间，也不是并发压测 P95。早期 111.43 秒记录包含逐请求加载开销，属于另一运行状态，不据此计算严格加速倍数。[常驻记录](experiments/resident_benchmark_v1.md)与[缓存记录](experiments/redis_cache_v1.md)包含逐任务数据。

## 发布范围

交付源码、配置、测试、复现命令、摘要语料与实验记录。实现为文本 RAG，未将 PDF 解析、LangChain 或 BLEU 列为已完成模块。候选第二轮数据和提示词探索归档，未启动第二轮训练。实际问答仍可能出现错误拒答、漏答或引用不完整，演示保留证据以便核对，面向知识科普与技术实验，不提供个人诊断。
